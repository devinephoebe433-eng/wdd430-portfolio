# Devine Phoebe Nabugobero — WDD 430 Portfolio

A responsive TypeScript portfolio built with the Next.js App Router and Tailwind CSS for Devine Phoebe Nabugobero.

Devine is a software developer affiliated with BYU-Idaho who enjoys reading, travelling, and continuing to learn through practical software projects. Her public GitHub profile describes her as Devine and includes the reminder: “Life with Christ has a meaning.”

The visual direction uses a polished feminine editorial system: blush, plum, rose, and lavender accents; serif display typography; soft rounded cards; and subtle decorative shapes balanced with accessible contrast and clear information hierarchy.

## Featured projects

- [WDD 430 Portfolio](https://github.com/devinephoebe433-eng/wdd430-portfolio) — Next.js, React, TypeScript, and Tailwind CSS portfolio.
- [CSE 341 Books and Authors API](https://github.com/devinephoebe433-eng/cse341-books) — Node.js and Express service with MongoDB Atlas, CRUD routes, related resources, and Swagger documentation.
- [StudySphere](https://github.com/devinephoebe433-eng/wdd330) — JavaScript web project with HTML, CSS, assets, and a project report.
- [CSE 340 course project](https://github.com/devinephoebe433-eng/cse340-course) — EJS/Node web project with a public Render deployment.
- [Devine's World](https://github.com/devinephoebe433-eng/wdd231) — HTML-based web development coursework project.

## Routes

- `/` — Devine's portfolio home page and project collection
- `/about` — Devine's background, interests, GitHub profile, and capabilities
- `/api/hello` — JSON API route returning `{ "message": "Hello from Next.js API!" }`

## Custom component

`components/SkillCard.tsx` accepts a `skill` and `detail` prop and displays a capability card on the About page.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
